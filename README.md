## 如何使用

1. 克隆此仓库到本地
2. 安装依赖：`pip install -r requirements.txt`
3. 创建`.env`文件并设置以下环境变量：
   ```
   VOLC_ACCESS_KEY=你的火山引擎访问密钥
   VOLC_SECRET_KEY=你的火山引擎密钥
   ```
4. 运行应用：`python 2.py`
